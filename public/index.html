    Hirdetés az oldalon

    A más weboldalakon látott automatikus bannereket a Google AdSense (vagy hasonló hálózat) tölti be. Partnerként közvetlenül is kérhetsz megjelenést az űrlapon.

    Google AdSense (automatikus hirdetések)

    1. Regisztrálj itt: google.com/adsense
    2. Add hozzá az oldalt, és várd meg a Google jóváhagyását.
    3. Az AdSense felületen hozz létre hirdetési egységeket (pl. „Display” / reszponzív).
    4. Másold be a kiadóazonosítót (`ca-pub-…`) és a slot ID-kat a data/ads.json → adsense részébe, majd állítsd "enabled": true-ra. 
    {
  "adsense": {
    "enabled": true,
    "client": "ca-pub-9316553426322212",
    "units": {
      "mid": "1234567890",
      "footer": "0987654321"
    }
  }

    Amíg nincs jóváhagyott AdSense-fiókod, a slotokon partner-hirdetések jelennek meg (lásd lent).
