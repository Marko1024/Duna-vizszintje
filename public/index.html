Riasztás beállítása

Böngésző-értesítés, ha egy állomás túllépi a megadott küszöböt. Az e-mail / push küldéshez később backend szolgáltatás köthető.

    Adatforrás

    Elsődleges forrás az OVF VRAQuery API (vmservice.vizugy.hu) nyilvános open-data tokennel. Ha az API nem elérhető, az oldal a hydroinfo.hu HTML tábláira esik vissza. Hivatalos felhasználónév/jelszó esetén állítsd be a VIZUGY_USERNAME / VIZUGY_PASSWORD környezeti változókat.
